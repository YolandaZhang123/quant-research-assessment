# Assistance and Source Disclosure

## Academic Sources

The following academic papers were consulted as background and motivation:

1. Jegadeesh, N. and Titman, S. (1993), "Returns to Buying Winners and Selling Losers: Implications for Stock Market Efficiency," The Journal of Finance, 48(1), 65-91.

2. Lee, C. M. C. and Swaminathan, B. (2000), "Price Momentum and Trading Volume," The Journal of Finance, 55(5), 2017-2069.

3. Gökçen, U. and Post, T., "Trading Volume, Return Variability and Short-Term Momentum," The European Journal of Finance.

These papers were used for background on momentum, trading activity and short-horizon return behaviour. The final study is not an exact replication of any of them.

## Data Sources

The project uses Massive U.S. equities data, primarily:

- Daily Market Summary / Aggregate Bars for daily OHLCV data;
- Historical Ticker Reference data for point-in-time common-stock universe construction.

No external market dataset was used in the final analysis. Raw Massive licensed data are not included in the submitted repository.

## AI Assistance

ChatGPT (OpenAI) was used as an AI assistant for conceptual clarification, research-design discussion, Python coding/debugging assistance, statistical-method explanation, and organization/editing of the research documentation.

All code was run locally by me, all outputs were inspected by me, and I remain responsible for understanding and defending the submitted methodology, code and conclusions.

The Massive API credential was never shared with the AI.

## External Code

No external research repository or third-party trading-strategy code was copied into the final analysis.

Standard documentation for the Python packages used in the project was consulted where necessary.
